# 🍽️ Saffron & Spice — Restaurant Website

A modern, elegant, and responsive restaurant website built with **React, Vite, JavaScript, and CSS**. This project showcases an attractive Indian restaurant interface with an interactive menu, shopping cart, food gallery, and WhatsApp-based order message flow.

🌐 **Live Website:** [https://saffron-spice-restaurant-website.netlify.app/](https://saffron-spice-restaurant-website.netlify.app/)

## ✨ Features

- 🎨 Premium and modern restaurant design
- 📱 Responsive layout for mobile, tablet, and desktop
- 🍛 Signature dishes with images and sample prices
- 🔎 Interactive menu search and category filters
- 🛒 Shopping cart with quantity controls and item removal
- 💰 Automatic subtotal and total calculation
- 💬 WhatsApp order message generation
- 🖼️ Food gallery and restaurant introduction
- 📍 Restaurant contact details and opening hours
- 📝 Contact form with frontend validation
- ⚡ Reusable React components
- 💾 Optional cart persistence using localStorage

## 🚀 Getting Started

### Prerequisites

Install Node.js and npm before running the project.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Nasima-dev/saffron-spice-restaurant.git
   ```

2. Navigate to the project folder:

   ```bash
   cd saffron-spice-restaurant
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

## 🏗️ Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## 💬 WhatsApp Order Flow

The website can prepare a WhatsApp message containing selected dishes, quantities, and the cart total.

Configure the restaurant's WhatsApp number in the appropriate project configuration file before using this feature for a real business.

**Note:** Customers must review and send the WhatsApp message themselves. Orders are not automatically stored or confirmed by a backend.
